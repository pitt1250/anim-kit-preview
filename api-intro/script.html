比喻對照表 metaphor → term

比喻術語正確定義出處比喻不像的地方（避免誤解）
顧客呼叫端（Client）發出請求、使用對方服務的程式。MDN Web Docs：API（Glossary）顧客可以臨時改口、跟服務生聊天；程式只能照 API 規格送出固定格式的請求。
菜單API 文件說明有哪些功能可以用、請求要怎麼寫、回應長什麼樣子。MDN Web Docs：API（Glossary）菜單只寫菜名和價錢；API 文件還會寫每個欄位的格式和可能的錯誤代碼，細很多。
服務生API一個軟體提供給其他程式使用的一組功能與規則，讓程式（而不是人）能和它互動：規定能請求什麼、怎麼請求、會得到什麼。MDN Web Docs：API（Glossary）API 不是一個人、也不會自己判斷；它是一套規則，格式不對就直接回錯誤，不會幫你猜。
點單請求（Request）呼叫端照 API 規格送出的訊息，寫清楚要做什麼、帶哪些資料。MDN Web Docs：HTTP messages點單寫錯，服務生可能會問你；請求格式錯了，對方會直接回錯誤。
主廚與廚房伺服器（Server）接到請求後實際處理的程式或系統。MDN Web Docs：HTTP messages伺服器不一定是「做」出新東西，也可能是查資料、計算、再轉給別的系統。
端回來的餐點回應（Response）伺服器處理完回傳的結果：成功的資料，或錯誤訊息加狀態碼。MDN Web Docs：HTTP messages餐點端回來通常就是成功；回應可能是錯誤，例如 404 表示找不到請求的東西。
